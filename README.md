# 🏎️ Garagem de Colecionador | Catálogo de Carrinhos

Um catálogo web simples, elegante e responsivo construído para organizar e exibir uma coleção de carrinhos em miniatura. Projeto desenvolvido para prática de desenvolvimento web e colaboração em família!

## ✨ Funcionalidades

- **Design Responsivo:** A grade de cartões se adapta automaticamente a telas de computadores, tablets e celulares.
- **Cartões Interativos:** Cada carrinho possui seu próprio card com foto, especificações (marca, fabricante, escala, ano) e descrição.
- **Efeitos de Hover:** Animações sutis em CSS ao passar o mouse sobre os veículos.
- **Badges Personalizadas:** Destaque para modelos raros ou favoritos na coleção.
- **Modo Escuro (Dark Theme):** Interface estilizada em tons escuros para destacar o colorido das fotos.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi desenvolvido do zero sem dependência de bibliotecas externas ou frameworks, utilizando apenas tecnologias web fundamentais:

- **HTML5:** Estruturação semântica da página e das especificações dos modelos.
- **CSS3:** Estilização, layout em **CSS Grid**, variáveis e efeitos visuais.
